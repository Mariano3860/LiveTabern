# Asset provenance

The room, furniture, props, flames, and action poses are original procedural work implemented in apps/web/scene.tsx. The 15 inhabitants combine compatible character meshes from Quaternius' Universal Base Characters and Modular Character Outfits — Fantasy packs. The selected Standard downloads are CC0 1.0 Universal and their source notices are retained beside the runtime files in `public/models/characters/quaternius/`.

Sources: [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) and [Modular Character Outfits — Fantasy](https://quaternius.com/packs/modularcharacteroutfitsfantasy.html). The downloaded archives were the free Standard versions, not paid source editions. Archive SHA-256 values: Universal Base Characters `FDBF1804C90DFC1EA03E992BFF7DA2DFD1A79318E13270A660180F9308455F40`; Fantasy Outfits `C3468B18871CC8C8F05AB14DF7712BAF22CB9F389CBD870BABF130E595187F70`.

The imported male/female head meshes and male/female Peasant/Ranger clothing are separate GLTFs sharing the same 65-bone rig. Each inhabitant receives an independent skeleton clone so its local action pose cannot affect another character. The base body is clipped below the neck where it would otherwise overlap the outfit. The original color maps are capped at 2048px and encoded as JPEG; 2048px normal, roughness, and ORM maps are encoded as WebP quality 98; smaller eye maps remain PNG. The current character asset set is 16.7 MB. The downloaded Standard license notices are `LICENSE-UNIVERSAL-BASE-CHARACTERS.txt` and `LICENSE-FANTASY-OUTFITS.txt` in the same directory.

Audio is generated with browser oscillators in apps/web/audio.ts; the melody is a short original eight-note loop. It is an initial sound representation, not a recorded band performance or generated vocal track.

The interface requests DM Sans and Playfair Display from Google Fonts, with system fallbacks. The fonts are external resources; their upstream source and license notices are available from the Google Fonts repositories. Self-hosting and recording exact font revisions is a production follow-up.

Tabletop bread and cheese, fruit, playing cards and dice, and a book with ink are original procedural variations selected deterministically by table index. Before adding further external runtime assets, record the source URL, exact file/version, license and notice file, transformations, and resulting size. A repository's source license does not automatically cover assets it links to.

The skeletal actions in `public/models/characters/quaternius/tavern-actions.glb` come from the official [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) and [Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html) Standard downloads by Quaternius. Both are CC0 1.0 Universal; the retained notice is `LICENSE-UNIVERSAL-ANIMATION-LIBRARY.txt`. Source archive SHA-256: UAL1 `CC73FC4E495B82958207316596317A3F40B9FA38065BDE1027937452DA537724`; UAL2 `4008EA208A604773A2B2177D965F0F5D3195498B5BF838C3F5785D68E95F2A68`.

The reproducible `scripts/pack-tavern-animations.mjs` build keeps twelve UAL1 clips (`Walk_Loop`, `Idle_Loop`, `Idle_Talking_Loop`, `Idle_Torch_Loop`, `Interact`, `PickUp_Table`, `Sitting_Enter`, `Sitting_Exit`, `Sitting_Idle_Loop`, `Sitting_Talking_Loop`, `Dance_Loop`, `Fixing_Kneeling`) and four UAL2 clips (`Consume`, `Idle_FoldArms_Loop`, `Idle_Lantern_Loop`, `Yes`). It remaps animation channels onto the shared character joints, and strips the source mannequin's mesh, materials, and skin. The resulting self-contained animation library is 3.13 MiB; SHA-256 `E03E843BD06DFDF0329C897BB3B25F51408F190D37F89334D90F94D13A84C8FD`. The build script asserts clip order, joint targets, and absence of duplicate geometry/skin.
